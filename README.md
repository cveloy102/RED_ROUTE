# RED_ROUTE

Нативный VPN-клиент для **Windows 10 22H2 / Windows 11 x64**. C# / .NET 10 / WPF,
служба Windows и встроенное официальное ядро Amnezia. Название режима всегда
сопровождается объяснением.

- **Вкл** — весь публичный интернет через VPN; локальная сеть остаётся доступна.
- **Выкл** — туннель остановлен, обычный интернет напрямую.
- **Авто** — выбранные сайты/сервисы через VPN, остальное напрямую.
- Импорт `.conf` AmneziaWG/WireGuard, несколько профилей, основной и порядок резервных.
- Живая проверка HTTPS через VPN на двух независимых адресах. После трёх неудачных
  циклов — освобождение туннеля и проверка следующего профиля.
- Кандидаты проверяются без установки маршрутов. При недоступности всех серверов
  интернет остаётся напрямую; повторы каждые 10 секунд после окончания предыдущего цикла.
- Трей, автозапуск интерфейса, экспорт/импорт правил, Geo-Aggregator, восстановление сети.
- Пользовательские настройки защищены DPAPI CurrentUser. Служебные — DPAPI LocalMachine
  в каталоге с ACL только SYSTEM/Administrators. Управление службой — через named pipe
  с доступом установившему пользователю, SYSTEM и администраторам.

## Установка

Собранный пакет: `artifacts/RED_ROUTE-0.1.1-win-x64.msi`.
Запустить установщик, разрешить UAC, затем открыть RED_ROUTE из меню «Пуск».
Мастер показывает приветствие и экран успешного завершения. Кнопка «Готово»
закрывает установщик и открывает приложение, если отмечен флажок запуска.
При отключённом UAC Windows не показывает запрос повышения прав.
На вкладке «Профили» добавить `.conf`; первым расположить основной сервер.
Добавить сайты на главном экране и выбрать «Авто» или «Вкл».
.NET и отдельный клиент Amnezia устанавливать не нужно: runtime и ядро входят в пакет.

Служба работает отдельно от окна. Крестик прячет окно в трей; «Выключить VPN и выйти»
останавливает VPN. После перезагрузки служба восстанавливает последний сохранённый режим.
Сам интерфейс запускается при входе, если включён соответствующий флажок.

## Разрешения и восстановление

Администратор нужен при установке/обновлении/удалении. Обычная работа — без UAC.
«Восстановить обычный интернет» запоминает «Выкл», останавливает собственное ядро,
освобождает его TUN/маршруты и очищает DNS-кеш. Профили и правила сохраняются.
Физические интерфейсы, настройки роутера и чужие VPN не сбрасываются.
Если служба недоступна, тот же обработчик запускает установленную службу с
`--recover` с UAC. Независимый ярлык: «RED_ROUTE — восстановить интернет».

## Сборка

Нужен Windows x64, .NET SDK 10.0 и Go 1.25.5. Поместить Go в `.tools/go`
либо передать путь в `scripts/build-engine.ps1 -Go ...`.

```powershell
./scripts/build.ps1
# После сборки ядра:
./scripts/build.ps1 -SkipEngine
# Проверки, не включающие VPN:
dotnet run --project tests/RedRoute.Tests -c Release
./src/RedRoute.App/bin/Release/net10.0-windows/RED_ROUTE.exe --smoke-test
```

WiX 6.0.2 автоматически восстанавливается как MSBuild SDK. Ядро собирается из
закреплённого commit; происхождение и лицензии см. [THIRD-PARTY.md](THIRD-PARTY.md).
Автоматизация GitHub собирает MSI и сохраняет артефакт при push, pull request или теге `v*`.

## Статус 0.1.1

Первая сборка для испытаний. Проверены сборка WPF/службы, парсер, режимы,
машина состояний резервов с управляемыми отказами, границы IPC, конфигурации через
`amnezia-box check` и рендер настоящих WPF-страниц. Реальное VPN-подключение пока
не проверено: нужен рабочий `.conf` и испытательный ПК/VM.

Обязательный живой прогон до передачи маме: установка/обновление/удаление на Windows
10 и 11, UAC, первый импорт, IPv4/IPv6, браузерный DNS, сон/смена сети,
обрыв во время трафика, отказ основного/всех профилей, сбой процесса службы,
обычное и аварийное восстановление. Не считать предварительные проверки
доказательством этих сценариев. Подробнее: [docs/VALIDATION.md](docs/VALIDATION.md).

## Ограничения

- Проверка потери связи занимает до трёх циклов (10 секунд между циклами, HTTPS timeout
  5 секунд). В этот промежуток уже направленные в VPN соединения могут ждать/обрываться;
  после обнаружения ошибки туннель снимается. Мгновенный бесшовный перенос TCP-сессий не заявляется.
- С рабочего резерва не прыгаем обратно на основной; новое включение начинает с основного.
- DNS приложения сохраняет доменные имена через FakeIP. Защищённый DNS браузера + ECH
  может скрыть домен; тогда доступны IP-правила, остальное идёт напрямую в «Авто».
- Конфиги с несколькими Peer, скриптами PostUp/PostDown, неизвестными полями и невалидными
  ключами отклоняются. Импорт поддерживаемых полей AWG 1/1.5/2/3 отражён в парсере.
- Пакет x64 и без цифровой подписи. ARM64/x86 не являются проверенными целями.
- Установивший пользователь назначается владельцем управления; многопользовательский
  интерфейс и смена владельца через UI пока не реализованы.

В отчёт не входят ключи, исходные конфиги, список посещённых сайтов или содержимое трафика.
Имена профилей и события соединения входят в отчёт, который пользователь сохраняет сам.
