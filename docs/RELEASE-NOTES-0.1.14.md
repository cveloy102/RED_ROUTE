# RED_ROUTE 0.1.14 — кандидат релиза

Исправлена потеря DNS-адресов после повторного аварийного завершения ядра. Если браузер уже сохранил адрес сайта, а перезапущенное ядро не выдавало новых адресов, следующий сбой мог удалить соответствия из кеша. Чтение сохранённого указателя теперь не удаляет его с диска.

Добавлен тест настоящего файлового DNS-кеша с четырьмя последовательными открытиями без штатного сохранения. Живая проверка дополнена тремя принудительными перезапусками установленного ядра без новых DNS-запросов между ними.

Исправлено обновление встроенного .NET: установщик больше не пропускает компоненты из-за более высокой версии отдельного файла старой установки. Все частные файлы среды заменяются согласованным набором; сборки приложения, службы и установщика используют .NET 10.0.13. Добавлены проверки наличия компонентов запуска в пакете.

Содержит исправления и обновления зависимостей 0.1.13. Версия остаётся предварительной до завершения проверок на чистых Windows 10/11, сна/пробуждения и независимых резервных серверов.
