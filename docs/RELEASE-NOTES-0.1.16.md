# RED_ROUTE 0.1.16 — проверка реального IPv6 через VPN

Исправлен сброс соединений полного VPN, если в `.conf` указан IPv6, но сервер не обеспечивает рабочий выход по IPv6. Приложение проверяет IPv6 отдельными HTTPS-запросами через профиль перед включением маршрутов. При неудаче используется IPv4, без изменения исходного профиля. Изменение доступности во время работы перестраивает маршрутизацию; неработающий IPv6 периодически проверяется повторно.

Исправлено раскрытие содержимого профиля в строковом представлении и имени элемента списка для системных средств доступности. Ключи и `.conf` больше не входят в эти представления; добавлена проверка настоящих WPF automation peers.

Включены исправления 0.1.15 для прямого IPv6, кешированных AAAA и переключения сети. Проверены обновление установленной версии, браузер, резерв, аварии ядра/службы и восстановление интернета. Подробные результаты и ограничения: [отчёт проверки](TEST-REPORT-0.1.16.md).

Версия остаётся предварительной: чистые Windows 10/11, физическая смена сети, перезагрузка/сон и независимые резервные серверы требуют отдельной приёмки.
