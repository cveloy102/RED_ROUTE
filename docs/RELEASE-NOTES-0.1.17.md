# RED_ROUTE 0.1.17 — завершение запуска туннеля

Исправлена проверка готовности ядра: локальный проверочный порт мог открыться раньше, чем завершалась настройка системного туннеля. Теперь служба ожидает отдельный сигнал после полного запуска ядра и только затем проверяет соединение и сообщает о подключении. Ожидание ограничено по времени и отменяется при восстановлении интернета.

Включены исправления реального IPv6-подключения и доступности профилей из 0.1.16, а также исправления кешированных адресов из 0.1.15. Ядро — redroute7. Проверка первого TCP-соединения после статуса «подключено» дополнительно контролирует, что оно использует адрес туннеля.

Версия предварительная. Подробности проверки и оставшиеся сценарии: [отчёт 0.1.17](TEST-REPORT-0.1.17.md).
