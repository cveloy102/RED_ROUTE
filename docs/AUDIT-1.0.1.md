# Аудит 1.0.1 и исправления

Аудит кода 1.0.1 (commit eb26890): чтение всех проектов, фаззинг парсеров и IPC (около 800 тыс. входов),
полный конвейер CI с native WG/AWG lab, govulncheck и WPF smoke. Регрессионные проверки исправлений лежат в
`tests/RedRoute.Tests/AuditFixChecks.cs`.

| # | Находка | Статус |
|---|---|---|
| 1 | Каталог `ProgramData\RED_ROUTE` мог быть создан заранее обычным пользователем; дочерние файлы сохраняли его ACL, а `runtime.json` с приватным ключом перезаписывался с этими правами | Исправлено: чужой каталог переносится в сторону и создаётся заново, права детей сбрасываются, `runtime.json` пишется новым файлом и удаляется при старте |
| 2 | «Вкл» без `strict_route`: Windows может параллельно отправлять DNS провайдеру | Исправлено: в «Вкл» включён `strict_route` (динамические WFP-фильтры блокируют порт 53 вне TUN, снимаются при завершении ядра); «Авто» без изменений |
| 3 | Одна неудачная IPv6-проба полностью переподключала туннель | Исправлено: смена IPv6-политики только после 3 подряд отличающихся результатов |
| 4 | `DNS` профиля игнорировался; split-tunnel профили импортировались, но не могли пройти проверку | Исправлено: используется частный DNS профиля внутри AllowedIPs; импорт профиля без полного охвата публичного IPv4 отклоняется с объяснением |
| 5 | `192.168.1/24` молча становился `192.168.0.1/24`, `10` — `0.0.0.10` | Исправлено: строгий формат IPv4 и длины префикса |
| 6 | Неучтённые исключения в обработчиках UI закрывали приложение | Исправлено: глобальный обработчик с журналом `Logs\ui-errors.log` и расширенные фильтры (отчёт, проверка, восстановление, автозапуск) |
| 7 | Ошибка сохранения или занятое имя пайпа роняли службу (FailFast) | Исправлено: ошибки обрабатываются в пределах одного запроса, клиент получает текст ошибки, создание пайпа повторяется |
| 8 | `[Interface] # комментарий` отклонялся | Исправлено; неизвестный раздел называется в сообщении |
| 9 | Ротация временных IPv6 и виртуальные адаптеры без шлюза вызывали переподключение | Исправлено: учитываются только адаптеры со шлюзом, для IPv6 — префикс до /64 |
| 10a | MSI распаковывался в `%TEMP%` пользователя и устанавливался с повышенными правами | Исправлено: распаковка в новую папку `%WINDIR%\Temp` с ACL только для администраторов |
| 10b | Проверенный установщик обновления можно было подменить до запуска через runas | Исправлено: файл удерживается открытым без права записи и удаления, хеш проверяется по этому дескриптору до старта процесса |
| 10c | Single-file `RED_ROUTE-Setup.exe` распаковывает нативные DLL WPF в `%TEMP%\.net` пользователя и загружает их с правами администратора | Открыто: нужно архитектурное изменение (например, без self-extract или WiX Burn bundle) |
| 11 | Гонка порта health-прокси | Без изменений: ядро (SYSTEM) завершится при занятом порте до отправки учётных данных, а перехват SO_REUSEADDR между учётными записями Windows запрещает |
| 12 | Приватный ключ в `runtime.json`, пока VPN подключён | Частично: файл с защищённым ACL удаляется при остановке и при старте службы; передача конфига без файла не реализована (stdin занят командой остановки) |
| 13 | stderr ядра выбрасывался целиком | Исправлено: в журнал событий попадает категория последней FATAL/ERROR строки без адресов, имён хостов и значений в кавычках |
| 14 | Нечитаемые настройки службы сбрасывались без копии | Исправлено: создаётся `.backup-*` |
| 15 | Иконка и меню трея пересоздавались каждые 2 секунды | Исправлено: перестройка только при смене режима, фазы или темы; опрос адаптеров вынесен из UI-потока |
| 16 | Исходники ядра скачивались архивом без проверки; IPv6-патч эндпоинта мог тихо не примениться; actions не закреплены по SHA; `contents: write` у всех сборок | Исправлено: `git fetch` точного коммита с проверкой `rev-parse`, проверка патча, SHA-pin, публикация вынесена в отдельную job с правом записи |
| 17 | Каталог берётся из HEAD стороннего репозитория | Без изменений: проектное решение, данные проверяются и ограничиваются |
| 19 | govulncheck (CI-шаг) находит достижимые GO-2026-6888 (brotli), GO-2026-6865 (klauspost/compress), GO-2026-6859 (net/http) — сборка 1.0.1 сейчас не проходит CI | Исправлено: brotli v1.2.7, compress v1.20.2, Go 1.26.11, ядро redroute9 |
| 18 | `*.example.com` отклонялся; MTU < 1280 запрещён и для IPv4; отчёт с IP-адресами без предупреждения | Исправлено (для профилей с IPv6 минимум MTU по-прежнему 1280) |
