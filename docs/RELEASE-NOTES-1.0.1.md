# RED_ROUTE 1.0.1

Исправлено добавление профилей AmneziaWG с расширенными параметрами.

- Поддерживаются флаги `on/off`, `true/false`, `1/0` и диапазоны `PersistentKeepalive`.
- Ошибка файла или повторное добавление объясняются прямо в окне импорта. Окно остаётся открытым, существующие профили сохраняются.
- «Сделать главным» переключает включённый VPN на выбранный профиль. Добавление резервного не прерывает здоровое подключение.
- Изменение профилей после «Восстановить интернет» не включает VPN обратно.
- Кнопки диалогов остаются видимыми при небольшой высоте окна.

Обновление сохраняет профили, правила и выбранную тему. Проверки и границы проверки описаны в [отчёте](TEST-REPORT-1.0.1.md).
