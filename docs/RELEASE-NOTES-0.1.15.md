# RED_ROUTE 0.1.15 — сборка для проверки

Исправлена причина сброса соединений в браузере на сетях без внешнего IPv6: RED_ROUTE больше не принимает соединение, которое затем пытается отправить по заведомо отсутствующему IPv6-пути. Недоступный вариант быстро уступает место IPv4. Рабочий IPv6 через VPN и локальная IPv6-сеть сохраняются; полный VPN продолжает перехватывать IPv6, чтобы не допускать обхода через провайдера.

Добавлена обработка реальных IPv6-адресов, оставшихся в кеше браузера. Для выбранного домена на IPv4-профиле адрес разрешается повторно через VPN; для невыбранного домена без прямого IPv6 — через обычный DNS. При изменении сетевого подключения параметры определяются заново.

Добавлены проверки реального предварительного выбора маршрута, повторных отказов TCP/UDP, кешированных AAAA и зашифрованного клиент-серверного обмена WG/AWG с IPv4-профилем и профилем IPv4/IPv6. Ядро: redroute6.

Сборка предварительная. Проверка установленной версии с браузером и реальными системными маршрутами запланирована отдельно; автоматические проверки не заменяют её.
