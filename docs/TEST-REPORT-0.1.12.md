# Проверка RED_ROUTE 0.1.12

- Из подсказок исключены категория 18+ и 6503 связанных домена. Совпадения и поддомены удаляются также из общих категорий и старого кеша.
- При обновлении базы список исключений обновляется до объединения сервисов и сохраняется в кеше. Скрипт подготовки встроенной базы применяет тот же фильтр.
- Пользовательские правила не удаляются; изменение касается каталога подсказок.
- 100 проверок C# пройдены, включая отсутствие взрослой категории и её доменов, фильтрацию старого кеша и сохранение обычных сервисов.
- WPF smoke: прокрутка внутри списка не закрывает его; прокрутка основной страницы закрывает список. Также проверены полный видимый каталог, поиск dis, выбор сервиса и диалоги.
- При перемещении или изменении размера окна список также закрывается.

Проверки выполнялись без команд VPN-службе и изменения пользовательской сети.
