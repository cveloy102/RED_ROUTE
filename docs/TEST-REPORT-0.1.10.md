# Проверка RED_ROUTE 0.1.10

- Сборка Release: без предупреждений и ошибок.
- 97 проверок C#: существующая логика VPN, каталог и обновления.
- Проверки обновления: версии, стабильность релиза, адрес установщика, обязательный SHA-256, загрузка, повреждённый кеш, отмена и неверная сумма.
- 8 проверок MSI: структура пакета, служба, восстановление и обновление.
- Изолированная проверка WPF: весь каталог при пустом вводе, фильтр dis, выбор Discord, уже добавленные позиции, кнопка обновления и окно загрузки.
- Интерфейс каталога дополнительно проверен через Windows UI в режиме --preview без пользовательских настроек и подключения VPN.

Полная установка обновления на рабочем компьютере не запускалась: пользователь проверяет переход с установщика 0.1.9 на опубликованный релиз 0.1.10 самостоятельно. Живые VPN-подключения и OpenVPN в этой проверке не менялись.
