# Проверка RED_ROUTE 0.1.11

Исправлен захват ввода выпадающим списком каталога. Popup больше не захватывает мышь; повторное открытие после нажатия выполняется после получения полем фокуса. Список закрывается при нажатии вне поля/списка, переключении страницы и деактивации окна. Escape из списка возвращает фокус в поле и закрывает каталог.

Ошибка воспроизведена в изолированной копии 0.1.10 через обычный ввод с клавиатуры: текст dis не попадал в поле. После исправления тем же способом проверено появление dis и подсказок Discord/Discourse/Disney+, а также удаление последней буквы Backspace до di. Программное присваивание Text не использовалось для этой проверки.

97 проверок C# пройдены. Пользовательские профили, VPN-служба и настройки сети при проверке не менялись.
