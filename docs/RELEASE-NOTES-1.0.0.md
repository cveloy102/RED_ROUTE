# RED_ROUTE 1.0.0

Первый стабильный выпуск нативного VPN-клиента для Windows 10 22H2 и Windows 11 x64.

- Оформление «Как в системе» по умолчанию, светлая и тёмная темы в разделе «Помощь». Выбор сохраняется; системная тема меняется без перезапуска. Общая палитра для окна, подсказок, диалогов, прокрутки, меню трея и установщика.
- Импорт AmneziaWG/WireGuard `.conf`, маршрутизация выбранных сайтов, полный VPN, резервные профили и проверка HTTPS во время работы.
- Проверка реальной доступности IPv6 и ожидание полного запуска туннеля; восстановление после аварий без потери уже выданных DNS-адресов.
- Уведомление о другом активном VPN. На проверенном ПК BRO_2 в AmneziaWG мешает подключению RED_ROUTE; поддержка двух одновременно работающих VPN не заявляется. RED_ROUTE не меняет настройки другого клиента.
- Обновление через GitHub Releases, установщик с непрерывным прогрессом и сохранением профилей/правил, отдельная команда восстановления интернета.

Основной файл установки — **RED_ROUTE-1.0.0-Setup.exe**. Предыдущие версии увидят обновление автоматически или через «Помощь → Проверить обновления».

Проверки и их границы: [отчёт 1.0.0](https://github.com/cveloy102/RED_ROUTE/blob/main/docs/TEST-REPORT-1.0.0.md). В полном VPN некоторые сайты могут применять региональные ограничения по стране VPN-сервера.
